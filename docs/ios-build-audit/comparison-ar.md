# مقارنة OpenMinis المعرّب مع المصدر الأحدث

تاريخ القياس: 19 أكتوبر 2026. هذا التقرير يفصل بين إصدار المصدر، وتعديلات التعريب والتثبيت الجانبي، وطريقة تغليف IPA.

## النسخ المقارنة

| النسخة | الإصدار | المرجع |
|---|---|---|
| فرع المستخدم المعرّب | 1.12 | `c47dcf33190072ede964a0ac39f7251290f4745b`؛ تعديلات 21 أغسطس، أساسه `09fc199` |
| أحدث مصدر منشور عند الفحص | 1.14 | `b4c0661d5631ebab4d1a2e6f3fd4c805d4030a6c`؛ 29 سبتمبر |
| App Store عند الاستعلام | 1.15 | إصدار 11 أكتوبر؛ بيانات Apple تعلن 416,843,776 بايت |

الفرع الجديد `build/ios-size-audit-20261019` يبدأ من المصدر الأصلي 1.14، مع سكربتات بناء وقياس فقط، دون نقل التعريب أو تعديل منطق التطبيق.

## الحجم المقاس

- IPA الجديد الكامل: **64,160,117 بايت = 64.16 MB = 61.19 MiB**.
- ملفات حزمة التطبيق الجديد بعد فكها: **133,496,473 بايت = 133.50 MB**، قبل بيانات المستخدم وفك بيئة Linux.
- يحتوي الجديد امتدادات المشاركة وFile Provider والويدجت الثلاثة؛ حجمها بعد الفك 4,876,700 بايت.
- للمقارنة فقط، إعادة تغليف التطبيق نفسه دون الامتدادات: **62,262,275 بايت = 62.26 MB**؛ ليس هذا ملف التسليم الكامل.
- IPA القديم المعرّب: **49,760,052 بايت = 49.76 MB**، وحزمة التطبيق بعد الفك **92,725,773 بايت = 92.73 MB**. لا يحتوي امتدادات PlugIns بحسب سير عمله الأصلي.
- الفرق المضغوط بين القديم والجديد الكامل: **14.40 MB**. وعند مقارنة الحزمة الجديدة دون الامتدادات بالقديم يصبح الفرق **12.50 MB**.

| المكوّن بعد فك الحزمة | 1.12 المعرّب، MB | 1.14 الكامل، MB |
|---|---:|---:|
| الملف التنفيذي Minis | 20.74 | 52.03 |
| Frameworks | 31.58 | 31.65 |
| الأيقونات Assets.car | 6.14 | 6.14 |
| الأيقونات البديلة | 5.55 | 5.55 |
| Alpine المضغوط | 3.98 | 3.98 |
| كتالوج النماذج | 3.62 | 4.86 |
| امتدادات PlugIns | محذوفة | 4.88 |

الزيادة الأكبر في الملف التنفيذي: **31.30 MB بعد الفك**. أضاف الإصدار الجديد rclone المبني بـGo ونظام النسخ والمهام؛ rclone مرتبط داخل الملف التنفيذي، وليس إطارًا منفصلًا في Frameworks. لا ننسب كل بايت من الزيادة إلى ميزة واحدة دون خريطة ربط تفصيلية.

الحجم المعلن في بيانات Apple لـ1.15 هو **416.84 MB / 397.53 MiB**. المقارنة مع IPA غير موقع ليست قياسًا لحجم تنزيل App Store لنفس الإصدار. تختلف نسخة المصدر، ومعالجة Apple وتشفير الملف التنفيذي وApp Thinning والموارد قد تغير الحجم. لا يثبت فرق الحجم وحده وجود ميزات مخفية أو اختلاف غير مشروع في المصدر.

## المميزات والتغييرات في iOS بين 1.12 و1.14

| المجال | فرع 1.12 المعرّب | المصدر 1.14 |
|---|---|---|
| المحادثة وLinux والمتصفح والمهارات والذاكرة وMCP والشخصية | موجودة | موجودة مع إصلاحات وتوسعات؛ ليست إضافات جديدة كليًا |
| الوكلاء الفرعيون | لا يوجد نظام Jobs/SubAgentDefinition الجديد | وكلاء متخصصون، اختيار نموذج، تفويض، طابور، متابعة وتوجيه وإيقاف واستئناف |
| الجدولة الداخلية | لا توجد أداة minis-scheduled الجديدة | تشغيل مرة واحدة أو دوري أو عند انتهاء مهمة، والرجوع إلى محادثة قائمة |
| النسخ والاستعادة | لا توجد وحدة Agent/Backup الجديدة | نسخ انتقائي بصيغة minisbak، تشفير اختياري، سجل وتقدم واستعادة، وجهات محلية وشبكية |
| وجهات النسخ الشبكية | لا يوجد دمج rclone الجديد | SMB وWebDAV وSFTP وS3 وFTP |
| GitHub Copilot | لا يوجد مزود مستقل | دخول device-flow وتحديث قائمة النماذج؛ تكامل غير رسمي |
| إعدادات الطلب لكل نموذج | إعدادات أساسية | إضافات temperature وtop-p وheaders وextra body للمسارات المتوافقة |
| إدارة السياق | ضغط وتلخيص موجودان | تقدير ومعايرة بحسب النموذج، معالجة تجاوز السياق، حدود للانتظار ومحاولات التلخيص، وتبديل النموذج عند فشل الضغط |
| تغيير النموذج أثناء المهمة | المسار القديم | تغييرات لجعل الاختيار يسري على الطلب التالي ومعالجة إعادة المحاولة بالنموذج السابق |
| المتصفح | تبويبات وأتمتة وCookies ولقطات شاشة موجودة | حدود زمنية لاستدعاءات JavaScript وإصلاح تسريب حقول كلمة المرور في backbone ومعالجة توقف الصفحة |
| سلامة كتابة الملفات | المسار القديم | رفض كتابة placeholders الناتجة عن تفريغ السياق فوق المحتوى الحقيقي وإصلاح حلقات إعادة قراءة النتائج الكبيرة |
| التشغيل المتعدد والأداء | أدوات متزامنة موجودة أصلًا | إدارة المهام الفرعية، تحسين تحرير المحادثات من الذاكرة، تشخيص الموارد، وإصلاحات عرض وبث |
| الصوت | إدخال وقراءة وتصحيح موجودة | إصلاحات التسجيل والتفريغ والتصحيح وتكامل السياق والتشخيص؛ لا يُنسب أصل الميزة إلى 1.14 |
| اللغات | الكتالوج السابق مع إضافة العربية | توسعة اللغات الأصلية والكتالوج، لكن العربية الخاصة بالمستخدم غير منقولة |

المقارنة من الكود نفسه. ملاحظات إصدارات GitHub معنونة Android؛ لا يُفترض أن كل بند فيها إضافة جديدة في iOS.

## التعريب وتعديلات المستخدم

- 1.12 يحتوي 1,788 مفتاحًا في Localizable.xcstrings، منها **85 مفتاحًا له ترجمة عربية**. العدد يصف تغطية الكتالوج، وليس نسبة الشاشات المرئية.
- 1.14 يحتوي **2,389 مفتاحًا**: زادت **601**، ولم يُحذف أي مفتاح من الكتالوج القديم في هذه المقارنة.
- جميع المفاتيح العربية الـ85 ما زالت موجودة، فتصلح ترجماتها للنقل دون تغيير أسماء المفاتيح.
- المصدر 1.14 لا يحتوي العربية أو تعديلات RTL الخاصة بالمستخدم. يلزم عند تحديث التعريب نقل الكتالوج وInfoPlist.strings وتسجيل اللغة وتوجيه الواجهة، ثم ترجمة النصوص الأخرى ومراجعة العرض.
- نصوص الترجمات العربية نفسها تبلغ 2,829 بايت UTF-8 فقط، دون أغلفة الملفات. لا تفسّر عشرات أو مئات الميغابايت.
- فرع المستخدم أضاف أيضًا fallback للتخزين عند غياب App Groups، وحماية لمسار تسجيل File Provider وترحيل المجلدات. هذه تعديلات تثبيت جانبي منفصلة عن التعريب، وغير موجودة في المصدر 1.14 الأصلي.
- سير عمل الفرع المعرّب يحذف PlugIns من IPA، لذلك يفقد الملف الناتج امتدادات المشاركة والملفات والويدجت. البناء الجديد الكامل يحتفظ بها.

## إضافات 1.15 في المتجر، خارج المصدر المقارن

تذكر ملاحظات Apple بطاقات لسؤال المستخدم والتأكيد، ومشاركة المحادثة كصورة طويلة أو PDF، والبحث داخل المحادثة، وتحسين متابعة الجدولة والحصص والعمل بالخلفية، وAOJIT لصور تنفيذ مسبقة التجميع. لا تُنسب هذه إلى 1.14 بمجرد أنها موجودة في المتجر. لا يمكن تحديد مساهمة AOJIT في الحجم دون فحص ملف 1.15 المقابل.

## نتيجة البناء والتشغيل

- **نجح بناء جهاز iOS للإصدار 1.14** وإنتاج IPA غير موقع مع كل الامتدادات، من المصدر الأصلي دون تعديل ملفات التطبيق.
- **نجح إعادة بناء فرع المستخدم 1.12** بسير عمله نفسه وإنتاج IPA غير موقع؛ لم نعدّل ذلك الفرع.
- **نجح بناء المحاكي وتثبيت الحزمة** بعد اختيار SDK المحاكي وإعادة تجميع ملفات LAME الوسيطة.
- **لم يثبت تشغيل واجهة التطبيق بنجاح على المحاكي**: محاولة التوقيع بالاستحقاقات الكاملة قُتلت بسبب `CODESIGNING / Taskgated Invalid Signature`؛ ومحاولة استحقاقات المحاكي الدنيا أعادت PID، لكن العملية ماتت قبل فحص العشرين ثانية، مع `CODESIGNING / Invalid Page` داخل dyld_sim أثناء تحميل المكتبات. هذه نتيجة تشغيل فاشلة، ولا تعني فشل بناء نسخة الجهاز.
- جرى ذلك على macOS ARM64 وXcode 26.6. لم يُختبر iPhone حقيقي أو اتصال بمزود نماذج.
- احتُفظ بتقريري الانهيار وملف `verification-result.json` حتى لا يُخلط نجاح التجميع مع نجاح التشغيل.
